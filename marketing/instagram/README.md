# Instagram carousels

One folder per blog post: `slide-1.jpg` … `slide-N.jpg` (1080×1350, upload in order) and `caption.txt`.
Each carousel is built from the post's own wording and uses its section emblem from `assets/emblems/`
(lantern = Policy & Practice, clipboard = On the Record, path = Career & Wellbeing, clock = the lateness post).
The last slide always points to the newsletter ("link in bio"), so keep grow2guide.substack.com in the Instagram bio.
Post each carousel the same day its Substack post goes out. Track posting in Notion: Substack Growth Tasks.

These files are marketing assets, not site pages; nothing on grow2guide.com links to them.
